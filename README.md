# Wedding Invitation v1

Prototipo mobile-first de invitación digital interactiva inspirado en la estructura del video de referencia.

Incluye portada cinematográfica, música, fecha para raspar, countdown, ceremonia y recepción, galería con lightbox, sugerencias de canciones, dress code, notas, regalos, QR de fotos, RSVP y descarga de calendario (.ics).

## Datos de demo

Los nombres, fecha, ubicaciones, cuenta de regalos y enlaces actuales son demostrativos. Se reemplazan cuando se tenga la información real del evento.

## Rama aislada

Esta versión vive únicamente en `wedding-invitation-v1`; no modifica el proyecto existente de `main`.
